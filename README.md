# What is the ModernUIs DisBridge Integration?

Integration to allow using DisBridge for ModernUIs Whitelist / Permission system.

### DisBridge

Website: https://vrc.disbridge.com/

GitHub: https://github.com/UdonVR/DisBridge

### ModernUIs

GitHub: https://github.com/DrBlackRat/VRC-ModernUIs

# How to use it

You can add the DisBridge To Whitelist Bridge Prefab to your scene under: 

`Tools > DrBlackRat > ModernUIs Integrations > DisBridge`
